TurboWarp Jotai Adapter

This TurboWarp extension describes Jotai atom registry, action envelope, and state snapshot JSON. It is a bridge contract, not a bundled Jotai runtime.

Intended role

Use blocks for declarative state descriptions, then pass the generated JSON to a React/Jotai host that validates and applies it with TypeScript hooks.
